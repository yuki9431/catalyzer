# 設計: 試合の展開に「オーバーリミットを覚醒と重ねずに使った」「最後のコストで覚醒が無かった」を足す

- ステータス: 実装済み
- 日付: 2026-10-09
- 関連 issue: #524(#391 の定義一覧 `static/analysis/patterns.js` に足す。#526 の上に積む)

## 1. 背景(実データの集計結果)
本人 3,314試合・他ユーザー22人 12,808試合(試合経過あり)で集計した。#524 の元の3候補(覚醒を余らせて終わった・相手の覚醒中に撃墜された・覚醒の回数で負けた)は勝率差が無いか逆向きのため足さない。

| 展開 | 本人 勝率(当てはまる/それ以外) | 他22人 | 向き |
|---|---|---|---|
| オーバーリミットを覚醒と重ねずに使った(OL 発動試合のみ) | 40.4% / 59.4% | 36.8% / 50.5% | 15人中15人 |
| 最後のコストで覚醒が無かった(最後のコストに入った試合のみ) | 39.9% / 55.1% | 37.4% / 47.6% | 12人中12人 |
| 同上に、溜まって3.5秒以内の撃墜を含めた場合 | 39.3% / 55.3% | 36.7% / 47.8% | 12人中12人 |

向きは他22人のうち、当てはまる/当てはまらない両側に各30戦以上ある人で数えた。

「最後のコストで覚醒を残したまま使わなかった」は僚機の撃墜で終わった負けを拾うため不採用。「先落ちして覚醒1回」はミッションには MIN_GAP 未満のため出さず、シートの見返し項目としてのみ置く(本人 57.0%/60.7%、他 49.0%/54.6%)。

## 2. 定義(patterns.js に3件追加。2-1・2-2 は sheet: true, goal: true、2-3 は sheet: true のみ)

### 2-1. `ov_solo`「オーバーリミットを覚醒と重ねずに使った」
- 対象: 自分の `exbst-ov`(OL 発動区間)が1つ以上ある試合。無ければ null
- true: 自分の OL 発動区間のどれも、自分の覚醒区間(`exbst-f/s/e`)と重ならない。重なり = `min(end) - max(start) > 0`(センチ秒の整数で比較)
- hits: 覚醒と重ならなかった `exbst-ov` の action
- note: `オーバーリミットを {t} に覚醒なしで発動しています` / 理由ラベル: `OL発動 {t}`

### 2-2. `last_cost_burst`「最後のコストで覚醒が無かった」
- 最後のコストに入った時刻: チームコスト 6000 から、自分・僚機の撃墜を時刻順に、落ちた機体のコスト(`ms_cost` / `partner_cost`)で引く。残りが `0 < 残り <= min(ms_cost, partner_cost)` になった撃墜の時刻 t(どちらが次に落ちても負け)。残りが一度もこの範囲に入らずに 0 以下になった、またはコスト不明・試合経過なしなら null
- true: (a) t の時点で自分の覚醒が無い、または (b) t より後の自分の撃墜 d があり、d を含む自分の `ex` 区間(start < d <= end。end が試合終了時刻と等しければ end+1秒。#526 の heldBurstDeaths と同じ)の start が d の3.5秒以内(`d - start <= 3.5秒`、ちょうどを含む)で、その start から d までに自分の覚醒(`exbst-f/s/e`)の発動が無い(溜まってそのまま撃墜)。比較はセンチ秒の整数
  - 覚醒が有る = 自分の `ex` または `exbst-f/s/e` 区間で `start <= t + 2秒` かつ `end > t`(撃墜で溜まったゲージの区間は撃墜の直後に始まるため2秒の猶予)
- hits: 最後のコストに入った撃墜(自分または僚機の action)に加え、(b) に当てはまった自分の撃墜
- note: `{t} に最後のコストに入りました。覚醒は使える状態ではありませんでした`({t} は最後のコストに入った撃墜の時刻) / 理由ラベル: `最後のコスト {t}`

### 2-3. `fall_first_one_burst`「先落ちして覚醒1回」(sheet: true のみ。goal にしない=coach.js の候補関数は作らない)
- test: 既存 `fall_first` の判定が null なら null、false なら false。true のとき、自分の覚醒区間(`exbst-f/s/e`)の数がちょうど1なら true、それ以外は false
- hits: 自分の最初の撃墜(fall_first と同じ)
- note: `{t} で先に撃墜され、覚醒は1回でした` / 理由ラベルは既定(`撃墜 {t}`)
- シートでの並び: 「後落ちした」の直後

## 3. 変更
- `static/analysis/patterns.js`: 上記3件。チームコスト 6000 は既存定数があれば再利用、無ければ patterns.js に1つ置く。`patternReason` は hits の語を定義ごとに変えられるようにする(既定は従来どおり `撃墜`)
- `static/analysis/coach.js`: 候補関数を2つ追加し `computeActionPlan` に登録
  - ov_solo: title `オーバーリミットは覚醒と重ねて使う` / condition `オーバーリミットを覚醒中に発動する(オーバーリミットを使わなかった試合は対象外)` / detail `覚醒と重ねずにオーバーリミットを使った試合は{count}(勝率{bad}%)。重ねた試合は勝率{good}%`
  - last_cost_burst: title `最後のコストに覚醒を持ち込む` / condition `最後のコスト(次にどちらが落ちても負け)に入った時点で覚醒が使える(入らなかった試合は対象外)` / detail `最後のコストに入った時点で覚醒が無かった試合は{count}(勝率{bad}%)。覚醒があった試合は勝率{good}%`
