# 設計: UI oracle(サンプルデータのプレビューと画面確認スクリプト)

- ステータス: implemented
- 日付: 2026-10-02
- 関連 issue: #422(親 #411)

## 方針
`tools/ui-check/` に Node 組み込みのみ(依存ゼロ)で3点を置く。static/ と index.html は無加工で配信し、決定性処理は CDP で注入する(#423/#424 で index.html が変わっても追従)。
- プレビューサーバー(Node http): 本番と同じパスで API をモックし、それ以外は static/ を配信
- サンプル投入ページ `/__preview/`: static/lib/db.js の `saveMatchesToDB` で IndexedDB に投入し localStorage 設定後 `/` へ遷移(initSession のキャッシュ有り実経路で描画)
- 画面確認スクリプト: CDP を `--remote-debugging-pipe` で自前実装(puppeteer 不採用)

## 主要判断
| 論点 | 採用 | 却下理由 |
|---|---|---|
| index.html | 無加工配信+CDP `Page.addScriptToEvaluateOnNewDocument` | 複製/文字列注入は #423/#424 で乖離・アンカー依存 |
| API | プレビューサーバーが本物のパスで応答 | fetch 差し替えは app.js 内部に依存 |
| IndexedDB | seed ページが db.js を import | 生 IDB 書込は定義が重複、renderReport 直呼びはログインフォームが残る |
| ビュー遷移 | ハンバーガー→.menu-item を click | localStorage 直書きは内部キーに結合 |
| CDP | 自前(pipe、約80行) | 依存追加は方針違反 |
| 隔離 | 画面ごとに BrowserContext+新規タブ | clearDataForOrigin は sessionStorage/ポーリング残存 |
| 比較 | バイト一致→不一致ならデコードしピクセル完全一致(許容0) | 閾値付きは非決定性を隠す |
| 安定化 | 250ms 間隔で連続2枚バイト一致まで(最大12回) | 固定 sleep |
| 幅 | Emulation.setDeviceMetricsOverride(D 1280x800 / M 390x844, dsf 1) | --window-size は最小500px |
| ハング | 全体180s、CDP 30s、nav 15s、要素待ち10s、プロセスグループ SIGKILL | --screenshot/--dump-dom はハング実績 |

## 共通手順(画面ごと)
新規 context+tab → Emulation(viewport, Asia/Tokyo)+determinism 注入 → Fetch.enable(自 origin は continue、外部 Image は1x1透過PNG、他外部は fail 計上) → navigate → 操作(el.click() / 入力 / scrollIntoView、各10s待ち。report 開始は /__preview/ から / への遷移完了を待つ) → 必須要素待ち → `UI_CHECK_INJECT` 注入 → 必須要素再判定 → fonts/img 待ち+scrollTo(0,0) → 安定撮影 → 基準比較 → console エラー判定。
必須要素: querySelectorAll のうち可視(getClientRects>0)で text を含むものが min(既定1)件以上。console エラー: exceptionThrown / consoleAPICalled error / Log.entryAdded error。

## 出力・終了コード・環境変数
`OK <id>` / `FAIL <id>: <理由>`(位置引数で画面 id を絞れる。存在しない id・0件は基盤エラー exit 2。絞り込み時は対象 id の actual のみ更新)(必須要素なし <sel> / console エラー / 外部リクエスト / ダイアログ / 画面が安定しない / 基準画像なし / 基準画像と不一致(n px, bbox。サイズ違いも同じ見出しで「サイズ違い」と併記))。最終行 `ui-check: <ok>/<total> OK`。終了 0=全OK, 1=FAIL, 2=基盤エラー(Chrome 起動失敗・タイムアウト)。実画像は tmp/ui-check/actual/<id>.png。SIGINT/SIGTERM は Chrome kill+tmp 削除後 exit 130。CHROME_PATH(Chrome 起動失敗メッセージにも明記) / UI_CHECK_TIMEOUT_MS(既定180000) / UI_CHECK_INJECT(`<id>:<js>`、故障注入)。baseline/meta.json に Chrome バージョン、不一致時は警告のみ。
